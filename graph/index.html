Comparative evidence graph

Deep-learning MRI reconstruction methods, 2018–2026, linked by the conditions they were measured in side by side. Select a method for its relative effectiveness and the methods it has been compared with.

Mertcan Özdemir · UMRAM paper in preparation

What is linked

Two methods are joined when at least one paper measured both under the same condition: same dataset, contrast, acceleration, mask and split. Node size follows the number of studies that evaluated the method.

Relative effectiveness θ

A model with one effect per condition and one per method is fitted to the reported values. The condition effects absorb what differs between papers, so θ rests only on side-by-side differences. It is given relative to the reference method, with a 95% interval.

Windows

Each three-year publication window is its own graph and its own fit. "All years" pools them into one graph, shown for orientation.

Data and code

Values were extracted from the published tables of each paper. The extracted data and the analysis code will be released with the paper.
